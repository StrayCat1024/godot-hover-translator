Godot Hover Translator

Godot 编辑器悬停翻译插件：鼠标划过英文，立即显示中文并朗读。

安装后即可使用。查词、联网翻译、朗读都是自动的，不需要 AI 大模型。

前往 GitHub 仓库查看源码和下载

核心功能与覆盖范围

  • 检查器 (Inspector)： 鼠标悬停在属性、节点名称上即时翻译。
  • 场景树 & 文件系统： 自动翻译节点名、类名、文件名。
  • 代码编辑器： 鼠标划过 add_child、queue_free 等代码立即显示中文释义。
  • 界面元素： 菜单、按钮、Tab 等原生 UI 的英文全量支持。

支持的操作系统

  • Windows： 完整支持，默认使用系统语音 (SAPI) 朗读。
  • macOS： 完整支持，默认使用原生 say 语音朗读。
  • Linux： 完整支持，默认使用 speech-dispatcher 或 espeak。
  • 注：Android / iOS / Web 版编辑器暂不支持，启用时会自动拦截提示。

安装方法

把 addons/hover_translator 文件夹复制到你的 Godot 项目，然后在 项目 → 项目设置 → 插件 中启用 Hover Translator 即可。
